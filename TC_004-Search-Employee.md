- **Test Type:** Functional Testing

## Test Data

1. Open the PIM module.
2. Select Employee List.
3. Enter EMP1001 in the Employee ID field.
4. Click Search.
5. Verify the displayed employee record.

## Expected Result
The system should display the employee record matching EMP1001.

## Actual Result
The employee record appeared with the matching Employee ID.
